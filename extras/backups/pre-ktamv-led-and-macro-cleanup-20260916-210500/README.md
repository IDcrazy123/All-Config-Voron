# Backup trước khi Tối ưu hóa kTAMV và Ẩn Macro Thừa

**Thời gian:** 2026-09-16 21:05:00
**Mục đích:**
- Sao lưu cấu hình `ktamv.cfg` (cả bản local trong repo và bản live trên máy in) trước khi bổ sung cơ chế kiểm soát ánh sáng LED chống chói vòi phun, tinh chỉnh tọa độ camera tự động và ẩn các macro con bằng tiền tố `_` để tinh gọn giao diện Mainsail.

**Danh sách file sao lưu:**
- `ktamv.cfg.local`: File cấu hình kTAMV trong kho lưu trữ trước khi chỉnh sửa.
- `ktamv.cfg.live`: File cấu hình kTAMV đang chạy thực tế trên máy in trước khi cập nhật.
