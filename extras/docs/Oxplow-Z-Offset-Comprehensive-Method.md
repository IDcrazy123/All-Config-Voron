# Oxplow 2.3.2 — current procedure

The current method and machine profiles are maintained with the integrated
[Oxplow package](../Printables-Package/README.md).
Read [the current ramp and result formula](../Printables-Package/Oxplow-Z-Offset-Comprehensive-Method.md).

The 2.3.2 machine files use patch-only, high-to-low Z0.280 -> Z0.200 mm and
51 rows; row 25 is nominal Z0.240. The old low-to-high Z0.150 -> Z0.350
lookup table belongs to retired 2.0.0 files. It must not be used for current
reports. Select the report paired with the actual file you printed.

The published project is [Universal Oxplow by Công Dương](https://www.printables.com/model/1846885-universal-oxplow-first-layer-z-offset-calibration), based on Maxim7745's method.
